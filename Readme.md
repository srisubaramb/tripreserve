# ✈️ TripReserve

TripReserve is a flight search web application that allows users to search and explore available flights based on their travel details.

The project uses **React + Vite** for the frontend and **Node.js + Express** for the backend.

## Live Demo : [TripReserve](https://tripreserve.vercel.app/)


## 🚀 Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- Redux
- React Router

### Backend

- Node.js
- Express.js
- Travelpayouts API
